PROJECT VISION

将有趣的想法，
变成真实的系统。

想象这样一个机器人：听到你的声音时会主动看向你、和你打招呼；它能观察周围环境，理解你的行为与表情，并与你聊天。

它还能控制机械臂完成触碰、抓取和其他动作，帮你按开关、递物体、敲键盘，甚至替你回复消息。今天，我们已经可以把这种科幻愿景做成系统原型。

FRAMEWORK

我们准备怎么实现这个愿景？

你们可以从语音、视觉和机械控制三个能力模块出发，把用户意图转化为机械臂在真实环境中的行动。

重点 · 自己定义真正想做的项目

鼓励每一组构思和 DIY 自己觉得有趣的小功能，甚至重构整个系统。

例如：捡球、敲键盘、扮演用户回复别人的消息、通过“撑地”让自己越过一个台阶、回答“你觉得谁更帅”并指向它认为的那个人……这些只是帮助打开思路的例子，你们完全可以提出不同的方向。

评分会参考想法的新颖程度、完成度和难度。我们同样鼓励探索与发现：哪怕原先设想的功能最终没有成功实现，只要实验带来了未预期的现象或对问题的新理解，也会获得相应加分。

LISTEN · REASON · RESPOND

语音交互 Agent

作为用户的主要交互入口，负责唤醒、语音识别、对话生成、功能调用、语音合成与播放。它既要理解用户，也要决定系统下一步调用哪些能力。

SEE · UNDERSTAND · LOCATE

视觉 Agent

提供视觉理解、检测与定位能力，例如理解场景、识别用户行为、检测人脸或目标位置，并结合机械臂运动估计目标在三维空间中的位置。

PLAN · CONTROL · ACT

机械控制 Agent

根据任务目标与视觉反馈生成并执行机械臂控制指令，例如转动机械臂调整观察视角、到达指定姿态，或将末端夹爪移动到目标点。

SYSTEM WORKFLOW

  • 01

    用户通过语音与语音交互 Agent 沟通。

  • 02

    视觉 Agent 提供环境上下文，例如当前看到了什么、人或目标物体在哪里。

  • 03

    语音交互 Agent 发起功能调用；每个调用可以形成视觉理解与机械控制的小闭环。

你们不需要照搬这张图。请按照自己的功能目标定义 Agent Workflow，也可以设计不同的 multi-agent system 框架、角色分工和通信方式。

EXAMPLE 01

追踪任务的闭环

  1. 用户提出“看着我”或“看着这个物体”的请求。
  2. 视觉 Agent 检测目标并返回图像位置。
  3. 机械控制 Agent 调整机械臂姿态，使目标保持在腕部相机视野的中央区域。
  4. 新动作产生新观测，系统持续更新并形成实时闭环。

EXAMPLE 02

触碰任务的闭环

  1. 用户提出“碰一下那个目标”的请求。
  2. 视觉 Agent 找到目标，机械臂改变观察视角以主动收集信息。
  3. 系统结合视觉与运动信息估计三维位置。
  4. 机械控制 Agent 规划动作并执行触碰，通过视觉反馈继续修正。

HOW WE EVALUATE

我们既看结果，
也看你们提出了什么问题。

想法与挑战

功能是否新颖、有趣或有用？你们选择的问题是否具有足够难度？

完成度

系统实际做到了什么？功能是否稳定，演示是否能够体现完整的感知—决策—行动过程？

过程与证据

实现思路、实验过程、成功与失败是否记录清楚？是否能解释关键设计选择？

探索与发现

是否发现了未预期的现象，或对问题形成了新的理解？有证据的发现同样值得加分。
