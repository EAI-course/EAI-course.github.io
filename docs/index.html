LEARNING PATH

A complete intelligence loop

The course follows one central question—how can a robot complete a real task?—and places algorithms, systems, and practice on one shared map.

01

From sensors to scene understanding

Perceive

Learn how robots use vision, touch, and proprioception to form reliable estimates of the world and their own state.

  • Multimodal sensing
  • 3D vision
  • State estimation
02

From representations to world models

Understand

Study how space, objects, actions, and causal relations become computational representations for prediction and reasoning.

  • Spatial representation
  • World models
  • Embodied cognition
03

From goals to action policies

Decide & Learn

Compare planning, imitation learning, and reinforcement learning for choosing actions under uncertainty.

  • Motion planning
  • Imitation learning
  • Reinforcement learning
04

From models to real robots

Build an Agent

Connect perception, language, decision-making, and control into a closed-loop system that works in the physical world.

  • VLA models
  • System integration
  • Sim-to-Real

COURSE PROJECT

Build an agent that can
complete a task live

Teams choose a well-scoped real task and work through problem definition, data and simulation, model training, system integration, and live evaluation. Success means a system that works reliably—and an explanation of why it succeeds or fails.
